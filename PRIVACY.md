# Privacy policy

**Effective date:** 2026-08-05

StarCompanion is a local-first desktop application. It reads files selected by
the user or discovered in local Star Citizen installations, including game
archives, localization files, configuration files, and logs. It may write
local settings, caches, ownership records, backups, diagnostics, and reviewed
localization overrides.

StarCompanion does not contain telemetry, analytics, advertising, crash upload,
remote configuration, an automatic updater, or an HTTP client. It does not
sell, share, or transmit user information.

**This program will not transfer any information to other networked systems
unless specifically requested by the user or the person installing or
operating it.** The current application has no feature that performs such a
transfer. User-clicked documentation links may open in the system browser; the
browser and destination site then operate under their own privacy policies.

Redacted diagnostics are created locally only after a user request. They omit
absolute paths, usernames, logs, ownership data, game strings, and user-authored
values. Exporting or sharing the resulting file is a separate user action.

StarCompanion does not require an account and does not operate a server. To
remove its data, close the application and delete its local data directory and
any localization override or backup files the user chose to create. Detailed
locations and recovery behavior are documented in the bundled offline help.

Questions and privacy-related reports may be opened in the public
[issue tracker](https://github.com/aj3/StarCompanion/issues). Security-sensitive
reports should use the private process in [SECURITY.md](SECURITY.md).
