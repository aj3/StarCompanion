### Description

StarCompanion is an unofficial, local-first desktop application that reads a
user's own Star Citizen installation to produce reviewed localization
overrides, expose evidence-backed mission reward information, and track local
blueprint ownership. It has no telemetry, automatic updater, remote
configuration, or automatic data download. All writes use preview,
confirmation, backup, integrity, and rollback controls.

### Reputation

StarCompanion has published Windows and Ubuntu releases from its public
Apache-2.0 repository. Releases are
linked to reviewed source, a tagged commit, a complete GitHub-hosted
Windows/Ubuntu test and build matrix,
hash-verified dependencies, a CycloneDX SBOM, packaged offline smoke tests, and
public SHA-256 values. The project is new and does not yet claim independent
media coverage or broad adoption. Add truthful third-party usage, download,
community, or review links here before submission when they become available.

- [x] Apache-2.0 license and project NOTICE are present.
- [x] No proprietary game data or third-party implementation is distributed.
- [x] v0.2.0 is already released in the form to be signed.

- [ ] Maintainer enables multi-factor authentication on the SignPath account.
- [ ] Add honest independent reputation evidence if available.
