# Governance

StarCompanion is maintained by [aj3](https://github.com/aj3).

- Maintainers may author and merge project changes.
- Contributions from non-committers require maintainer review.
- Security reports are handled privately under [SECURITY.md](SECURITY.md).
- Release signing requires a tagged public commit, successful required CI, and
  a separate approval in the protected `release-signing` environment.
- Signing-policy, workflow, artifact-configuration, dependency, and packaging
  changes receive security-focused review before a signed release.

Maintainers and signing approvers must use multi-factor authentication for
GitHub and SignPath access. Project decisions are recorded in issues, pull
requests, release notes, or checked-in documentation.
