# Security policy

## Supported releases

The latest published release receives security fixes. Older releases may be
replaced rather than patched separately.

## Reporting a vulnerability

Do not post exploit details, sensitive paths, logs, credentials, or private
game data in a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/aj3/StarCompanion/security/advisories/new)
to report a suspected vulnerability.

Include the affected version, operating system, impact, reproduction steps,
and the smallest safe synthetic sample. Reports are acknowledged as soon as
practical, investigated privately, and disclosed after a fix is available.

The reviewed trust boundaries and security assumptions are documented in
[docs/THREAT_MODEL.md](docs/THREAT_MODEL.md).
