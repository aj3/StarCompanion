# Test samples

Deliberately **not** committed — these are copies of CIG's shipped localization
strings, and redistributing game data is out of bounds for this project. Tests
that need them skip automatically when absent.

To populate locally:

- `global.ini` — from your own Star Citizen install, or the StarStrings release
  at `src/For_Players/Data/Localization/english/global.ini`
- `contracts.ini` — from StarStrings at `src/For_Tool_Creators/contracts.ini`
